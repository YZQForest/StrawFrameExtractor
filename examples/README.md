# 实际示例输出

`inputs/中文 样例.mp4` 是程序生成的 2 秒合成测试视频（640×360，60000/1001 fps），不是田间科研素材。

`run_demo/` 是使用默认 2 fps、高质量 JPEG、保持原始尺寸得到的真实输出：4 张图片、metadata.csv、extraction.log、run_config.json 和 run_summary.json。

前三个非零选取时间分别为 0.500500000、1.001000000、1.501500000 秒。它们来自实际源帧 PTS，并不强行取整为 0.5、1.0、1.5 秒。毫秒文件名四舍五入，所以第二张包含 t000000000501。

配置、日志和 CSV 中原本记录的开发机器绝对路径，已统一改写为相对仓库根目录的路径（如 `examples/inputs/中文 样例.mp4`、`ffmpeg/ffmpeg`），其余内容与生成时一致。程序自己生成的任务仍记录绝对路径；在其他电脑上可用 output_filename 从 images 中定位。本例用于检查输出格式，建议在自己的 Windows 上新建任务测试，而不直接续跑此示例。

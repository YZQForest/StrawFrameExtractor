最短操作流程

  1. 填写标注者。点击左侧图片；本机入口默认载入启动 12 幅。
  2. 一般先「整幅填背景」，用绿色画笔 / 多边形标出可见秸秆。土壤孔隙保留背景。
  3. 橙色标材料不确定，灰色只标非地面 / 人物工具等遮挡。不要把阴影或难判的地面随意排除。
  4. 放大检查整幅，勾选三项检查，再点「标记完成并到下一幅」。
  5. 「导出完成项」得到完整研究包。Mac 本机服务会自动校验并保存到 human_masks；离线 HTML 会下载 ZIP。

类别与导出

材料掩码：0 背景、255 秸秆、128 材料不确定；草稿额外允许 64 未标。有效地面另存 0 / 255 掩码。训练掩码：0 背景、1 秸秆、255 忽略争议 / 未标 / 无效。原图、来源 SHA-256、裁块坐标、标注者、日期、检查记录和覆盖率区间一并导出。

材料不确定仍在有效地面分母内。下界 = 已知秸秆 / 有效地面，上界 =（已知秸秆 + 不确定 + 未标）/ 有效地面。只有不存在不确定 / 未标时才提供单一覆盖率值。

描绘与快捷键

1 秸秆 · 2 背景 · 3 不确定 · 4 排除遮挡 · 5 恢复地面 · 0 擦回未标。B 画笔 · P 多边形（双击 / Enter 闭合，Esc 取消）· R 矩形 · H 移动。按住空格拖动画面，滚轮滚动；⌘/Ctrl + 滚轮以指针为中心缩放。＋/− 缩放，［/］调整笔宽，Tab 切换叠加，⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做，←/→ 换图。

恢复与独立复标

浏览器自动保存包括原图和像素数组，但清除浏览器数据可能丢失工程，请定期「备份全部进度」。同一工具导出的 ZIP 可用「恢复数据包」在另一台电脑继续。独立复标必须新建空白工程；重复标注者是不是另一人，由记录和研究审核判断，工具不自动宣称独立一致性。
